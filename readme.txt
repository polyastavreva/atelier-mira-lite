A calm, editorial block theme for hair salons, barbers and beauty studios.

== Description ==

Atelier Mira Lite is a one-page block theme for hair salons, barbers and beauty studios. The home page is built from five patterns: a photo collage hero with your best numbers, a scrolling services band, a studio intro with a signature, a price menu with durations set like a printed card, and opening hours with your address and a booking button. Everything is edited in the Site Editor. No page builder and no extra plugins.

Features:

* Full Site Editing block theme with templates for the home page, blog, archive, search, pages, single posts and 404
* Five reusable patterns in the "Atelier Mira Lite" category
* Fonts bundled with the theme (Instrument Serif and DM Sans), so no requests go to Google Fonts
* Mobile-first layout with a full-screen phone menu
* Subtle photo animations, switched off for visitors who prefer reduced motion
* Translation ready

Atelier Mira (the full version) adds team, gallery and review sections, an appointment request form and WooCommerce styles for selling gift cards and products: https://stavreva68.gumroad.com/l/atelier-mira-wordpress-theme

== Installation ==

1. In your WordPress admin go to Appearance → Themes → Add New Theme.
2. Search for "Atelier Mira Lite", click Install, then Activate.
3. Go to Appearance → Editor → Templates → Front Page to edit the home page.

== Frequently Asked Questions ==

= How do I change the photos? =
The theme comes with soft placeholder images marked "Your photo" in the best size for each spot. Click a photo in the Site Editor, choose Replace and upload yours.

= How do I connect the booking button? =
Select the "Book online" button in the Visit section and paste the link to your booking page (for example Fresha, Booksy or Treatwell).

= How do I change colours and fonts? =
Appearance → Editor → Styles. The palette is Plum, Rose, Blush, Paper, Olive and Sage.
